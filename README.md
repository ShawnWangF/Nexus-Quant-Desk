# Nexus Quant Desk

本项目是一个本地运行的量化交易研究与模拟审批工作台，支持富途 OpenD 实时行情，也支持东方财富公开行情。默认使用本地空模拟账户，持仓配置保存在浏览器本机。

## 启动

```powershell
npm install
pip install -r requirements.txt
npm run dev -- --host 0.0.0.0
python server.py
```

然后打开 http://localhost:5173/。

## 行情源

- 富途 OpenD：在本机启动 OpenD 并监听 `127.0.0.1:11111`，适合实时报价和 K 线。
- 东方财富：通过本地 `server.py` 访问公开港股行情接口，国内部署可直接选择。
- 同花顺：界面保留适配入口，但需要你拥有并配置官方授权接口或 Token，项目不会伪造未授权连接。

行情源可在页面右上角“行情源”设置中切换。模拟账户只记录本地成交，不会调用真实交易下单接口。

## 模拟账户

首次打开默认没有内置持仓。点击“配置持仓”新增代码、名称、数量、成本、方向和风险等级；量化建议会以当前行情生成交易票据，审批后才会更新现金、持仓和成交记录。
